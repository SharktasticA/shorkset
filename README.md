# SHORKSET

A settings program for SHORK Operating Systems such as [SHORK 486](https://github.com/SharktasticA/SHORK-486). It can offer access to the following settings:

* Display resolution
* Drivers
  * Framebuffers
  * Network interfaces
  * PCMCIA bridges
  * Sound cards
* Dynamic swap
* Keyboard layout (keymaps)
* Font
  * Colour
  * Style (PSF)
* Mouse
  * General purpose mouse (gpm)
    * Enable/disable
    * Mouse type
    * Responsiveness
* Network
  * Enable/disable
  * Interfaces
* Splash screen
  * Enable/disable
  * Splash only
  * Splash with log messages
  * Splash with progress bar
* Volume
