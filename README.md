# SHORKSET

A settings program for SHORK Operating Systems such as [SHORK 486](https://github.com/SharktasticA/SHORK-486). It can offer access to the following settings:

* Display resolution
* Drivers
  * Network interfaces
  * PCMCIA bridges
  * Sound cards
* Keyboard layout (keymaps)
* Font
  * Colour
  * Style (PSF)
* Mouse
  * General purpose mouse (gpm)
    * Enable/disable gpm
    * Mouse type
    * Responsiveness
* Networking
  * Enable/disable networking
  * Interfaces
* Volume
